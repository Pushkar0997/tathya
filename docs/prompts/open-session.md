# Opening a session

Paste this into any coding agent before it does anything.

```
Read AGENTS.md, then CONTRACT.md, then spec/plan.md and spec/tasks.md.
Then read the top 3 entries of AGENT_LOG.md.

Tell me: which milestone is active, what was in progress, and which task
you propose to do next. Do not write any code yet.
```

If the reply proposes work from a future milestone, or cannot name the last thing that happened, it did not read the files. Start a fresh session rather than correcting it.
